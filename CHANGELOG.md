## [0.1.0] - 2026-11-27

### Added

- Initial project requirements and documentation.
- React Native mobile application using Expo and TypeScript.
- Modular mobile architecture.
- Five primary application screens.
- Bottom tab navigation using React Navigation.
- Strongly typed navigation routes.
- Active and inactive navigation icons using Ionicons.
- English and Spanish internationalization.
- Automatic device language detection.
- Manual language selection from the profile screen.
- Persistent language preferences using AsyncStorage.
- Application initialization loading and error states.
- Mobile architecture documentation.

### Changed

- Refactored the initial application into independent screen components.
- Separated navigation configuration from the root application component.
- Centralized translation resources.

### Fixed

- Installed the required expo-font peer dependency.

### Known Issues

- A moderate security vulnerability affecting the minimatch transitive dependency is pending remediation.
- Nutrition tracking features have not yet been implemented.
- The current user interface uses provisional styling.
